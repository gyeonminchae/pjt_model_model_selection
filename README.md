# [보고서] Agent 요청 실패 예측 모델 피처 엔지니어링 및 교차 검증 결과 보고

** 기본 필수 **

## 1. 개요

* **목적**: Agent 요청(Request) 데이터 기반의 '실패(Failed)' 예측 정확도를 높이기 위해, 입력 데이터 특성(Feature) 전처리 방식에 따른 모델 성능을 비교하고 최적의 학습 계획을 수립하고자 함. 또한, 교차 검증(CV) 결과를 바탕으로 최적의 피처 엔지니어링 및 모델 구조를 자동으로 선정한 뒤, 개발 데이터(80%)로 재학습을 수행하고 최종 격리된 테스트 데이터(20%)를 통해 객관적인 성능을 검증함. 

* **주요 방법론**:
    * 데이터 누수(Data Leakage) 방지를 위해 Test 세트를 완전히 분리한 상태에서 **Train/Validation 내부 3-Fold Stratified Cross-Validation** 수행
    * 불균형 데이터 분류에 적합한 **F1-Score**를 핵심 평가 지표로 채택

* **결과 요약**: 입력 특성 중 `input_chars`라는 원본 특성의 단독 사용과 로그 변환 특성(`log_input_chars`) 추가 사용 방식을 교차 검증하여 최적의 피처 조합 및 모델 설정을 확정함.

## 2. 실험 및 모델 비교 결과

동일한 모델 알고리즘(`DecisionTreeClassifier`, `max_depth=3`)과 검증 환경 하에서 두 가지 피처 구성안의 성능을 비교했습니다.

* **비교 대안**:
    1. `original` : 기존 입력 글자 수 특성만 사용(`input_chars`)
    2. `with_log` : 로그 변환된 글자 수 특성 추가 사용(`input_chars`, `log_input_chars`)
* 평가 지표: 3-Fold 교차 검증 평균 F1-Score(`CV_F1`) 및 표준편차(`CV_std`)

| 피처 구성안 (Features) | 3-Fold 평균 F1-Score (CV_F1) | 표준편차 (CV_std) | 비고 |
| :--- | :--- | :--- | :--- |
| **original** (`input_chars`) | *0.167* | *0.236* | 기준 모델 |
| **with_log** (`input_chars`, `log_input_chars`) | *0.167* | *0.236* | 로그 변환 적용 |

## 1. 개요
* **목적**: Agent 요청(Request) 데이터 기반의 '실패(Failed)' 예측 정확도를 높이기 위해, 입력 데이터 특성(Feature) 전처리 방식에 따른 모델 성능을 비교하고 최적의 학습 계획을 수립하고자 함. 또한, 교차 검증(CV) 결과를 바탕으로 최적의 피처 엔지니어링 및 모델 구조를 자동으로 선정한 뒤, 개발 데이터(80%)로 재학습을 수행하고 최종 격리된 테스트 데이터(20%)를 통해 객관적인 성능을 검증함. 

* **주요 방법론:** 
  * 사전 교차 검증(`feature_comparison.csv`) 결과를 참조하여 최고 성능을 보인 모델(`selected`)을 동적으로 채택

  * 임계값(Threshold) `0.5`를 기준으로 실패 여부를 최종 판정하고 다각도 평가지표(F1, AUC, 혼동행렬) 산출
